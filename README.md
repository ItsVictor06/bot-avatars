# bot-avatars

Repo publico con avatares para bots (Google Chat / Slack / Discord). Las imagenes se
sirven por `raw.githubusercontent.com` con `content-type: image/png` y sin auth, que es
lo que piden los campos tipo `avatarUrl`.

## Vanessa
| Archivo | Uso |
|---|---|
| `vanessa/avatar-512.png` (512x512, 318 KB) | avatar principal |
| `vanessa/avatar-256.png` (256x256, 94 KB) | avatares pequenos / listas |
| `vanessa/vanessa-original-1254.png` | original sin tocar (1254x1254, 1.7 MB) |
